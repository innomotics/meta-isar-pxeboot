# Support

## Documentation

Before opening a request, please check the existing documentation:

- [README.md](README.md) — build and test instructions
- [docs/user-quickstart.md](docs/user-quickstart.md) — installing images on target devices
- [docs/pxe-boot-installer.md](docs/pxe-boot-installer.md) — technical deep dive

## Questions and Bug Reports

Use the [GitHub issue tracker](https://github.com/pocketbroadcast/meta-isar-pxeboot/issues)
for questions, bug reports, and feature requests. Please search the existing
issues first — your topic may already be covered.

When reporting a problem, include:

- the kas configuration used for the build (e.g. `kas-pxe-boot.yml`)
- the host OS and whether the build ran via `kas-container` or natively
- the target machine and the relevant part of the build or boot log

## Security Issues

Do **not** report security vulnerabilities through public issues. Follow the
process described in [SECURITY.md](SECURITY.md) instead.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to submit changes.

Support is provided by the maintainers listed in [MAINTAINERS](MAINTAINERS) on
a best-effort basis; there is no guaranteed response time.
